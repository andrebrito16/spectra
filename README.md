## About

Spectra is a native macOS application, built from the ground up with Apple's modern app stack:

- **SwiftUI** for a fully native, responsive interface
- **SwiftData** for on-device persistence
- **App Sandbox** and **Hardened Runtime** enabled by default

> [!NOTE]
> Spectra is in early development — expect rapid changes. Star the repo to follow along!

## Getting Started

```sh
# Clone the repository
git clone https://github.com/andrebrito16/spectra.git
cd spectra

# Open in Xcode
open spectra.xcodeproj
```

Then select your development team under **Signing & Capabilities** (automatic signing is enabled) and hit **⌘R** to build and run.
