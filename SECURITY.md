# Security reports

Spectra is early alpha. Security fixes target the latest source on the default branch; older versions do not have a separate support commitment.

Do not open a public issue containing exploit details, credentials, kubeconfigs, or private cluster data.

If GitHub's **Report a vulnerability** button is available on this repository's Security tab, use it for a private report. Otherwise, open an issue that says only that you need a private security contact, and wait for the maintainer to establish a private channel before sharing details. No response-time guarantee is currently offered.

A useful private report includes the affected commit or version, macOS version, reproduction steps with synthetic data, expected impact, and any proposed fix. Remove credentials and identifying cluster data from attachments.
